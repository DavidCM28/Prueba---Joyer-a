# Prueba Joyería — visual direction

## World

Editorial urbano de flash directo: galería de campaña, no e-commerce de lujo. La página mezcla negro carbón, blanco hueso, plata fría y un azul eléctrico como destello de cámara. La composición es asimétrica, con tipografía comprimida, rotaciones pequeñas, marcos y cortes abruptos.

## Color tokens

- `--ink-950`: #08090A — fondo principal
- `--ink-900`: #111214 — superficies
- `--paper-100`: #F1F0EC — texto principal
- `--paper-300`: #B9B8B3 — texto secundario
- `--chrome`: #A9B0B8 — metal frío
- `--flash`: #13486C — azul profundo de acento, reservado para foco/CTA
- `--accent-ink`: #F1F0EC — contenido sobre el acento
- `--line`: rgba(241,240,236,.18)

## Type

Display: Bebas Neue, uppercase, compressed, oversized. Body/UI: Space Grotesk. Mono labels: IBM Plex Mono. Headings use balanced wrapping and compact tracking.

## Motion

Motion is a material: entrance reveals use springy stagger; marquee is constant but slow; product tiles tilt/scale on hover; the hero has a cursor-like flash dot. Respect reduced motion by disabling non-essential transforms and marquees.

## Responsive rules

Mobile-first. Navigation collapses to a compact rail, gallery becomes horizontally scrollable, hero uses an offset stack, and the main CTA remains easy to reach. Desktop expands into a 12-column asymmetric grid without centering every block.

## Avoid

No generic gradient hero, no glassmorphism, no fake testimonials, no invented prices, no symmetrical card grid, no soft wellness copy.
